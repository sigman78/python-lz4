the `lib/` files from the official LZ4 v1.10.0 release:
https://github.com/lz4/lz4/releases/tag/v1.10.0

Retrieved from https://raw.githubusercontent.com/lz4/lz4/v1.10.0/lib/

update this provenance and the library version in the README/changelog, and
retain the license. The extension reports `LZ4_VERSION` from the linked library.
